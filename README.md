# Spotify UI Clone 🎧

A responsive Spotify-inspired music streaming UI built using **HTML** and **Tailwind CSS**.

## Features
- Fully responsive layout (mobile, tablet, desktop)
- Fixed sidebar and sticky header
- Clean playlist grid UI
- Spotify-style dark theme

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
